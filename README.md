# Bitácora Regenerativa — demo

Prototipo móvil para registrar señales de regeneración durante un recorrido de cacao.
Sitio estático: `index.html` + `sw.js` (funciona sin señal) + `manifest.webmanifest` (instalable).

Se publica en GitHub Pages desde la rama `gh-pages`. Para actualizar: `git push origin main main:gh-pages`.
